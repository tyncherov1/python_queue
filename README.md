# 🎓 Очередь на семинар — Telegram-бот + Электронная доска

Единое приложение на Python (**FastAPI + aiogram 3 + WebSockets + SQLite**) для удобной организации очереди учеников к преподавателю на семинаре.

Telegram-бот и веб-сайт для интерактивной доски работают **в одном процессе** и синхронизируются в реальном времени: ученик подтверждает запись в Telegram — и его имя мгновенно появляется на доске; преподаватель нажимает **«Следующий человек»** на доске — и ученику сразу приходит уведомление в Telegram.

---

## ✨ Возможности

### 🤖 Telegram-бот
- **Строгий белый список (32 ученика в `students.csv`)**: посторонним пользователям бот **вообще ничего не отвечает** (полное игнорирование без сообщений об ошибках).
- **Удобная авторизация по `telegram_id` или `@username`**: можно заполнить только `@username` в таблице — при первом сообщении бот сам привяжет `telegram_id` ученика.
- **Запись с подтверждением**: кнопка `📝 Записаться в очередь` → инлайн-сообщение с кнопками **`✅ Подтвердить`** / **`❌ Отмена`**.
- **Точное место в очереди**: сразу после записи и по кнопке `📍 Моё место` бот сообщает позицию и **после кого именно идёт ученик** (включая того, кто сейчас отвечает).
- **Просмотр всей очереди**: кнопка `📋 Вся очередь` (или `/queue`) показывает текущего отвечающего с остатком таймера, весь список с отметкой `👈 Вы` и кнопку `🔄 Обновить`.
- **Отказ от очереди**: кнопка `❌ Выйти из очереди` (или `/leave`) с подтверждением (если ученик стоит в очереди дважды — можно выбрать, какую именно позицию отменить).
- **Умный кулдаун от записи к записи + лимит мест**:
  - отсчёт кулдауна (по умолчанию **15 минут**, легко меняется в `.env`, в боте или на сайте) идёт **от момента прошлой записи к следующей записи**, а не от завершения ответа у преподавателя;
  - спустя 15 минут после записи ученик может **записаться ещё раз**, даже если его первая запись ещё в очереди (например, стоять сразу на **#1 и #7**);
  - лимит одновременных мест в очереди на одного ученика (`MAX_ACTIVE_SLOTS`, по умолчанию **2**, `0` — без ограничений) не даёт забить всю очередь одному человеку;
  - при добровольном выходе из очереди действует короткий антиспам-кулдаун (**2 минуты**), чтобы случайное нажатие не блокировало надолго.
- **Автоуведомления**: когда преподаватель вызывает следующего, ученик получает пуш `🔔 Ваша очередь!`, а идущий за ним — `⏳ Приготовьтесь, вы следующий(ая)!`.
- **Полноценная админ-панель (`/admin`)**:
  - добавление любого ученика из списка (или по имени вручную) **в начало, в середину на любую позицию или в конец** (игнорируя кулдаун и без пометки «админ» на доске);
  - перемещение выше/ниже, на точную позицию `#N`, обмен двоих местами (`🔄 Поменять с...`), удаление;
  - вызов следующего (`/next`) и **отмена случайного вызова** (`↩️ Вернуть назад`);
  - **📢 рассылка объявлений** (всем в очереди или всей группе);
  - **📥 экспорт отчёта семинара в Excel CSV** прямо в чат Telegram;
  - открытие/закрытие записи, настройка таймера, кулдауна и лимита мест на лету, перезагрузка `students.csv`, очистка очереди и статистика.

### 🖥️ Сайт для электронной доски (Dark Mode)
- **Тёмная высококонтрастная тема**, адаптированная для проектора и интерактивной доски (крупный шрифт, табличные цифры таймера).
- **Круговой + цифровой таймер** (по умолчанию **7 минут**, легко меняется в `.env` или кнопкой `⚙️` прямо на сайте):
  - запускается **по нажатию** `▶ Старт` (при желании в настройках можно включить автостарт);
  - меняет подсветку: спокойный бирюзовый → жёлтое предупреждение за 1 минуту → красный пульсирующий овертайм `+00:15` после `00:00`;
  - **звенит по истечении времени** через встроенный Web Audio API (3 мелодии на выбор + регулятор громкости + кнопка проверки звука `🔊`, никаких внешних mp3-файлов).
- **Удобное управление на семинаре**:
  - `⏭ Вызвать первого` / `⏭ Следующий человек` — работает в любой момент, в том числе **до истечения таймера**;
  - защита от холостого запуска: пока из очереди никто не вызван, кнопки таймера заблокированы;
  - `+1 мин` и `↺ Сброс`, а также горячие клавиши (`Space` Старт/Пауза, `Enter`/`→` Следующий, `+` +1 мин, `R` Сброс, `F` Полный экран, `M` Звук);
  - **живой таймер во вкладке браузера** (`⏱ 04:32 — Фамилия`) и **расчёт общего времени очереди** (`~42 мин`) рядом со счётчиком;
  - в настройках (`⚙️`) — **↩️ Вернуть предыдущего** (отмена случайного нажатия «Следующий») и **📥 Скачать отчёт CSV** для Excel.
- **Правая панель очереди**: первые несколько человек (по умолчанию 7, настраивается) с выделением следующего (`#1`), кнопкой раскрытия полного списка, **QR-кодом на Telegram-бота** и режимом быстрого редактирования очереди прямо с доски (`✏️`).
- **Защита сайта и пароля (`BOARD_PIN`)**:
  - ученики могут открыть сайт на телефонах в режиме просмотра, а управление разблокируется паролем / PIN-кодом преподавателя (с кнопкой **👁 показать/скрыть пароль**);
  - **защита от подбора пароля (брутфорса)**: нарастающая серверная задержка при ошибках + **блокировка IP на 15 минут** (`PIN_LOCKOUT_MINUTES=15`) после 5 неверных попыток (`PIN_MAX_ATTEMPTS=5`) с обратным отсчётом на экране и **уведомлением админам в Telegram** о попытке взлома;
  - **подписанные HMAC-токены сессии** (сам пароль не хранится в `localStorage`), постоянное время сравнения (`hmac.compare_digest`), лимит запросов и WebSocket-соединений на IP, защитные HTTP-заголовки (`CSP`, `X-Frame-Options: DENY`, `nosniff`, `no-referrer`) и автоматическое скрытие `/docs` при заданном пароле.

## 🚀 Быстрый старт (локально)

### 1. Клонирование и установка зависимостей
```bash
python -m venv .venv

# Windows (PowerShell):
.\.venv\Scripts\Activate.ps1
# Linux / macOS:
# source .venv/bin/activate

pip install -r requirements.txt
```

### 2. Создание Telegram-бота
1. Откройте [@BotFather](https://t.me/BotFather) в Telegram и отправьте `/newbot`.
2. Задайте имя и username бота (например `msu_seminar_queue_bot`).
3. Скопируйте выданный **токен** (`123456:ABC-DEF...`).
4. Узнайте свой числовой Telegram ID у [@userinfobot](https://t.me/userinfobot) — он понадобится для `ADMIN_IDS`.

### 3. Настройка `.env`
Скопируйте `.env.example` в `.env`:
```bash
# Windows PowerShell:
Copy-Item .env.example .env
# Linux / macOS:
# cp .env.example .env
```
Откройте `.env` и заполните минимум два поля:
```env
BOT_TOKEN=ваш_токен_от_BotFather
ADMIN_IDS=123456789
DEFAULT_TIMER_MINUTES=7
REJOIN_COOLDOWN_MINUTES=15
BOARD_PIN=1234
```
> 💡 Если оставить `BOT_TOKEN` пустым, сайт всё равно запустится в **демо-режиме** — можно сразу открыть доску и покликать таймер с кнопкой `+ Тестовый ученик`.

### 4. Заполнение таблицы учеников (`students.csv`)
Откройте [`students.csv`](students.csv) в **Excel**, **Google Sheets** или любом текстовом редакторе. В файле уже сгенерирован шаблон на 32 ученика:

| id | full_name | telegram_id | username | role |
|---:|---|---:|---|---|
| 1 | Абрамов Артём Сергеевич | | student_01 | student |
| 2 | Алексеева Дарья Игоревна | 987654321 | | student |
| 3 | Белов Максим Андреевич | | maxim_belov | admin |

- Достаточно указать **либо `telegram_id`, либо `username`** (без `@`, регистр не важен).
- Поддерживаются оба разделителя — запятая `,` и точка с запятой `;` (как сохраняет русский Excel), а также кодировки UTF-8 и Windows-1251.
- Чтобы дать ученику/старосте права админа, поставьте `admin` в колонке `role` (или добавьте ID в `ADMIN_IDS`).
- После правки файла во время работы бота просто нажмите `📄 Перечитать CSV` в `/admin` (или отправьте `/reload`).

### 5. Запуск

```bash
python run.py
```

Локальный адрес доски: **http://localhost:8000**

## ☁️ Публичный доступ через Cloudflare Tunnel

Чтобы открыть электронную доску по публичному HTTPS-адресу (например, с интерактивной доски в аудитории или с телефонов учеников), используйте **Cloudflare Tunnel** (`cloudflared`) — регистрация и привязка карты не требуются.

### 1. Установка `cloudflared`

**Windows (PowerShell):**
```powershell
winget install --id Cloudflare.cloudflared
```

**Linux (Debian / Ubuntu):**
```bash
curl -L https://github.com/cloudflare/cloudflared/releases/latest/download/cloudflared-linux-amd64.deb -o /tmp/cloudflared.deb && sudo dpkg -i /tmp/cloudflared.deb
```

**macOS (Homebrew):**
```bash
brew install cloudflared
```

### 2. Запуск туннеля

1. Запустите приложение (`python run.py`), чтобы сервер работал на `http://localhost:8000`.
2. В соседнем терминале запустите туннель:
   ```bash
   cloudflared tunnel --url http://localhost:8000
   ```
3. В консоли появится временный публичный HTTPS-адрес вида `https://<случайное-имя>.trycloudflare.com` — скопируйте его и откройте на электронной доске (кнопка `F` — полный экран) или передайте ученикам.

> 💡 Telegram-бот при этом работает в режиме `polling` и продолжает отвечать через обычное интернет-соединение, пока запущен сервер.

## 🛠️ Команды Telegram-бота

### Для учеников
- `/start` — приветствие и кнопки меню
- `/join` — записаться в очередь (с инлайн-подтверждением)
- `/leave` — отказаться от очереди
- `/status` — текущая позиция и после кого вы идёте
- `/queue` — вся очередь целиком
- `/help` — справка

### Для администраторов
- `/admin` — интерактивная админ-панель со всеми кнопками
- `/next` — вызвать следующего ученика
- `/insert <позиция> <фамилия или имя>` — вставить ученика на конкретное место (например: `/insert 2 Иванов`)
- `/move <откуда> <куда>` — переместить позицию (например: `/move 5 2`)
- `/swap <поз1> <поз2>` — поменять двоих местами (например: `/swap 1 3`)
- `/remove <позиция>` — удалить ученика из очереди
- `/reload` — перечитать файл `students.csv` без перезапуска
